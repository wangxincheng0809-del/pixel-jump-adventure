# 超级跳跃 · 像素冒险

一个纯前端、零依赖的横版像素跳跃游戏，打开网页就能玩。

## 在线试玩

GitHub Pages：<https://jvrr952nnt-cmd.github.io/pixel-jump-adventure/>

## 玩法

- `方向键` / `A D` 左右移动
- `空格` / `W` / `↑` 跳跃
- `Shift` 加速奔跑
- `P` 暂停，`R` 重新开始
- 手机端会自动显示左下、右下的虚拟按键

## 内容

- 3 个关卡（草原漫步 / 岩壁回廊 / 尖刺迷城），难度递进
- 顶砖块、问号块得金币，能量果变大（变大后受伤只缩小不掉命）
- 踩刺虫得分，掉坑、碰尖刺、被撞会掉命，每关 240 秒倒计时
- 分数、金币、生命、关卡、时间 HUD，通关结算与重开
- 视差滚动云层山丘、粒子飘字、WebAudio 合成音效> 本页由 GitHub Pages 直接以 main 分支根目录发布。

## 文件结构

```
index.html   页面与样式
config.js    常量与工具函数
levels.js    关卡数据与构造器
engine.js    物理、输入、音效、游戏流程
render.js    精灵、绘制与主循环
```

## 说明

本作是致敬经典横版平台跳跃玩法的**原创**网页小游戏：角色、美术与关卡均为代码绘制，不使用任何第三方素材或商业 IP 资源。
